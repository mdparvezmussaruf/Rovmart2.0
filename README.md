# NOIRÉ Fashion Store

A lightweight fashion e-commerce storefront built with HTML5, CSS3, Vanilla JavaScript, Google Sheets and Google Apps Script.

## 1. Folder structure

```text
fashion-ecommerce/
├── index.html
├── product.html
├── style.css
├── products.js
├── cart.js
├── order.js
├── app.js
├── config.js
├── assets/
│   └── products/
└── google-apps-script/
    └── Code.gs
```

## 2. Add product images

Put your images in:

`assets/products/`

Then set the matching path in `products.js`, for example:

```js
image: "assets/products/black-shirt.jpg"
```

The same image is automatically used on the landing and detail pages.

## 3. Google Sheet

1. Create a Google Spreadsheet.
2. Open **Extensions → Apps Script**.
3. Replace the default Apps Script with `google-apps-script/Code.gs`.
4. Save.
5. In Apps Script, open **Project Settings** and set the timezone to `Asia/Dhaka`.
6. Deploy → **New deployment**.
7. Select **Web app**.
8. Execute as: **Me**.
9. Who has access: choose the public/anonymous access option available to your Google account.
10. Deploy and authorize the script.
11. Copy the Web App URL.
12. Paste it into `config.js`:

```js
const CONFIG = {
  GOOGLE_SCRIPT_URL: "YOUR_WEB_APP_URL"
};
```

## 4. Sheet columns

The script automatically creates the `Orders` sheet and headers:

- Order ID
- Date
- Time
- Customer Name
- Phone
- Delivery Address
- Product IDs
- Product Names
- Quantities
- Unit Prices
- Subtotal
- Total Amount
- Order Status
- Additional Note

Date/time are generated by Apps Script in `Asia/Dhaka`, not by the customer's browser.

## 5. Keep backend prices synchronized

The browser catalog is in `products.js`.

For price integrity, the Apps Script has its own authoritative catalog in:

`CONFIG.PRODUCTS`

When changing a product price, update BOTH locations.

## 6. Test locally

A local web server is preferable because browser security policies can interfere with `file://` pages.

If you have Python installed:

```bash
python -m http.server 8000
```

Then open:

`http://localhost:8000`

Do not open `index.html` directly from `file://` when testing API functionality.

## 7. Product URL

Products use one dynamic detail page:

`product.html?id=P001`

No separate HTML file is required for every product.

## 8. Important deployment note

Google Apps Script is the order API. The frontend can be deployed on any static hosting service that supports HTML/CSS/JS.

Do not put private credentials or service-account keys in frontend files.

## 9. Before production

- Replace sample product images.
- Replace the brand name and copy.
- Synchronize backend product prices.
- Test several single/multi-item orders.
- Test mobile layout.
- Test invalid phone/address data.
- Test duplicate-click protection.
- Protect edit access to the Google Sheet.
- Consider adding an admin workflow for order status updates.
